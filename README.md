🚨 Bomb Cops

Bomb Cops is an intense, top-down arcade survival game that blends high-speed drifting with tactical demolition. You aren't just running from the law, you're navigating a minefield of police interceptors, environmental hazards, and precision airstrikes. How long can you survive the heat?

🚧 Project Status: Under Development

Notice: This project is currently in its early development phase.
Mechanics are being tuned for better "drift-feel."
Visual assets and UI are subject to change.
New enemy types and power-ups are being added frequently.
We are currently focused on stabilizing the core "cat-and-mouse" loop and optimizing performance for a seamless experience.

🏎️ Gameplay Overview

In Bomb Cops, the desert is your playground and your prison. The police will use every tactic to pin you down, from heavy-ramming SUVs to calling in orbital strikes.

Key Features

Tactical Drifting: Use momentum to slide around enemies and lead them into obstacles.

The "Bomb" Mechanic: Turn the tide by using explosive power-ups to clear a path when the sirens get too loud.

Airstrike Evasion: Keep a constant eye on the ground; red targeting reticles mean you have seconds to move before a missile lands.

Escalating Difficulty: The longer you survive, the more aggressive the pursuit becomes.


🎮 Controls (WIP)

Steer: Left / Right Arrows or On-Screen Joypad.
Special: Space or Bomb Icon to trigger collected explosives.
Reset: R to restart a run.
